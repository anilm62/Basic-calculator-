Development Overview**
1. **Objective**: Build a basic calculator with arithmetic operations (+, -, ×, ÷), clear (C), delete (DEL), and percentage (%) functionalities.
2. **Tools Used**: HTML, CSS, JavaScript.
3. **Key Features**:
   - Responsive UI with hover effects.
   - Error handling for invalid expressions.
   - Decimal and percentage support.

### **Challenges & Solutions**
- **Decimal Handling**: Restricted input to one decimal per number using checks.
- **Error Prevention**: Used `try...catch` to handle invalid calculations.
- **Display Overflow**: Limited display to two decimal places for readability.
